### Main Projects

**[Nomos](https://github.com/pablonvsx/nomos)** — Main project to date, developed during master's research (PPGEO/UFPE). A mobile application for environmental inventories, built around a methodological protocol for landscape cartography, replacing analog field records with a structured and reproducible digital workflow.

**[KuchlerApp](https://github.com/pablonvsx/kuchler-app)** — Mobile application for automated vegetation physiognomy inventory, based on the Küchler method. Registers field plot data and automatically generates standardized physiognomic formulas and descriptions.
